# 이전 판들

`old/` 에 있는 세 묶음이 본편에 이르기까지 어떻게 이어지는지 적는다.

## 2009-11-prototype

`prototype.gmk` 는 게임메이커 7 프로젝트로, 유닛 능력치를 `global.ex_*` 배열로 빼고 하나의 유닛 오브젝트가 그 값을 읽는 구조를 처음 시도한 엔진 시험판이다. 유닛 그림은 프로젝트 안에 두지 않고 `sploz\spl_<id>_<n>.prmt` 에서 실행 중에 읽는다. `.prmt` 는 비밀번호가 걸린 zip 이고 `ml_uns.dll` 로 풀어 `sprite_add` 한다. 첫 룸에서 바로 2000x2000 시험 룸으로 넘어가며 드래그 선택, 미니맵, 자원, 8인 시작점이 돌아간다. 정의된 유닛은 주민 하나이고 메뉴와 네트워크는 없다.

## 2009-12-planning

게임메이커 8로 옮겨 처음부터 다시 짠 판이다. 능력치, 그림, 소리, 지형, 트리거, 맵을 전부 폴더별 `.dlrc` 아카이브로 두는 구조를 설계했고, 각 폴더의 `notes.ko.txt` 와 `dlrc-format.ko.txt` 에 그 설계가 적혀 있다. `.dlrc` 는 DLL 없이 GML 만으로 만든 아카이브로, 텍스트 색인 뒤에 바이트를 섞은 본문이 붙는다.

- `new-ml2.gmk`: 전장의 안개와 미니맵 안개를 새로 짠 시연. 유닛은 시야만 찍는 빈 오브젝트다.
- `terrain-editor.gmk`: 지형 PNG 를 이름과 함께 `sy_tri\tri_<n>.dlrc` 로 묶는 도구. 추가, 프레임 추가, 이름 바꾸기, 복사, 삭제, 폴더로 풀기가 된다.
- `map-editor.gmk`: 지형 아카이브를 읽어 칠하고 `.maps2` 로 저장하는 맵 에디터. 지형 편집만 있고 불러오기와 유닛 배치는 없다. 지형에디터와 같은 gameId 라 그 프로젝트에서 갈라져 나온 것이다.

이 dlrc 설계는 이후 판에 쓰이지 않았다. 본편은 능력치를 평문 txt 로, 그림을 `.gmspr` 로 둔다.

## 2010-02-dongto-yeomyeong

전작 동토의 여명이다. `v1.0/dongto-yeomyeong-v1.0.gmk` 가 소스이고 `v1.2-decompiled/dongto-yeomyeong-v1.2.gmk` 는 v1.2 실행 파일을 디컴파일한 것으로, 둘은 같은 gameId 에 룸 구성과 스크립트가 거의 같다. 디컴파일본 쪽이 조금 나중 빌드라 스프라이트 둘과 오브젝트 하나가 더 있다.

39dll 로 방을 만들고 들어가는 멀티플레이, 1vs1 부터 4vs4 까지의 로비, 컴퓨터 AI, 조선 9종과 슬라임 8종 유닛이 갖춰진 완성형이다. 유닛을 숫자 id(조선 0부터 8, 슬라임 100부터 107)로 다루는 구조와 UI 스프라이트 이름이 본편으로 그대로 이어졌다. 본편은 여기서 네트워크를 자작 FN Simple Scripts 로 바꾸고, 프로젝트 안에 있던 유닛 그림과 능력치 스크립트를 실행 파일 밖 파일로 뺀 판이다.
